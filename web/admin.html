系统 · 规则
Agent 决策规则总览
这里写明系统遵守的硬约束、软偏好和异常处理策略

🚫 硬约束（不可越界）

  • 商户价格 ≤ 用户预算
  • 商户在用户出发时间内营业
  • 勾选「别太远」时，taxi 时长 ≤ 30 分钟
  • 带孩子时，仅 kid_friendly = true 的商户进候选
  • 硬约束失败：直接淘汰，不计入排序
  • ad_bid 永远不能凌驾硬约束

⭐ 软偏好（参与评分）

  • photo：标签含 出片 / 拍照 / 网红 +10
  • good_food：餐厅评分 ≥ 4.5 +8
  • easy_pace：标签含 低强度 / 室内 / 轻松 +6
  • culture：标签含 文艺 +6
  • light_food：标签含 清淡 / 轻食 +8
  • 距离 ≤ 15min +5，≤ 25min +2

📣 广告权重（佣金旋钮）

  • ad_weight = min(15, ad_bid ÷ 8000)
  • final_score = match_score + ad_weight
  • ad_weight ≥ 3 → 前端打「推广」标
  • 用户拒绝过的商户从此抑制，ad_bid 再高也不再推

🛟 异常局部重排（不重做整方案）

  • restaurant_full：同商圈换 EAT，PLAY 不动
  • ticket_soldout：同商圈换 PLAY，EAT 不动
  • time_conflict：整条行程顺延 60 分钟
  • 被换掉的节点进 rejected_ids 抑制池

🚸 ADDON 安全规则

  • transport = self_drive → 过滤 alcohol = true 的商户
  • has_kid = true → 仅 kid_friendly = true 商户
  • 预算余量不足 → 跳过推荐

🤖 LLM 限制

  • 整个项目 LLM 只调 2 个点
  • parse_request：一句话 → 结构化（8s 超时）
  • compose_share_card：方案 → 群聊文案（5s 超时）
  • 失败永远走规则兜底，不崩
